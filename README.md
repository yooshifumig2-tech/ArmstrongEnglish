# Armstrong English Craft Lab

面向小学低年级学生的游戏化英语学习网站。学生通过收集单词方块、在 3×3 工作台中排列词块并“合成”完整英语句子来完成学习任务。

## 功能

- 4 个主题区域、16 张分级英语配方
- 点击或拖拽词块完成句子合成
- 英语朗读、中英双语切换、即时反馈与渐进提示
- XP、星星、连胜、成就、错题重练与本地进度保存
- 题目级 FUMI AI 苏格拉底式辅导面板
- 学习报告、区域掌握度和 ORID 学习反思
- 桌面端与移动端响应式布局

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

Netlify 的构建与发布目录已在 `netlify.toml` 中配置。
